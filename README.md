# CLI Compilation and Execution

1. Open CMD
2. Navigate to the directory containing the source code file
3. The main file to run this application is Talabia.java
4. Compile the source code using the following command; </br>
   javac -cp .;guava-18.0.jar Talabia.java
5. Execute the program using this command </br>
   java -cp .;guava-18.0.jar Talabia
